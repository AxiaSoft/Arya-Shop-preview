# ارائه — طراحی، توسعه و سئوی وب با AI (مطالعه موردی: آریاشاپ)

فایل `arya-ai-deck.html` یک ارائهٔ کامل ۱۰ دقیقه‌ای است — همه‌چیز در همان یک فایل (استایل، تصاویر وایرفریم، و متن گفتار).

**نحوهٔ استفاده:**
- کافی است فایل را در مرورگر باز کنید (یا از GitHub Pages سروش کنید)
- `→` / `←` یا Space: جابه‌جایی اسلایدها · سوایپ لمسی هم فعال است
- `N`: متن گفتار همان اسلاید · `T`: متن کامل ارائه · `O`: نمای کلی · `Esc`: بستن
- `Ctrl+P`: خروجی PDF (هر اسلاید یک صفحه)
