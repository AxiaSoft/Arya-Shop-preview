# ارائهٔ آریاشاپ — «هوش مصنوعی؛ سازندهٔ مدرن وب»

- فایل اصلی: `arya-ai-deck.html` — تک‌فایل، خودکفا، بدون وابستگی اینترنتی (فونت وزیرمتن از CDN با fallback)
- طراحی ریسپانسیو واقعی (۱۲ اسلاید + صفحهٔ پایان): هر اسلاید تمام‌صفحه با تایپوگرافی سیال (clamp/min(vw,vh))؛ روی دسکتاپ، لپ‌تاپ، موبایل افقی و عمودی بدون برش — در صفحه‌های کوتاه، اسلاید خودش اسکرول داخلی دارد
- ارائه‌دهنده: آریین علوی — استاد درس: جناب آقای خوبی — درس: برنامه‌نویسی مبتنی بر وب
- انیمیشن اختصاصی هر صفحه: ریوایل پلکانی، شمارندهٔ اعداد، ذرات پس‌زمینه، اسپاتلایت ماوس، درخشش تیترها (با رعایت prefers-reduced-motion)
