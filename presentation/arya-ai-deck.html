بریف و مسیر کار

هر پروژه از یک بریف شروع می‌شود — و AI در شش ایستگاه کنار کار بود

  • بریف آریا: فروشگاه فارسیِ راست‌به‌چپ که روی هاست اشتراکیِ ارزان اجرا شود، پنل مدیریت کامل، لایهٔ امنیت و سئوی واقعی داشته باشد
  • روش کار: نوشتن یکباره نه؛ شکستن بریف به شش تکر — هر تکر: پرامپت مشخص → پیاده‌سازی → تست در مرورگر → ممیزی امنیتی AI → تکر بعد
  • خروجی هر ایستگاه را با نمونهٔ زندهٔ آریا می‌بینید: طراحی → مهندسی → ریسپانسیو → سئوی فنی → سئوی محتوا → کیفیت
  • در پایان، یک تور زنده از محیط سایت و پنل و بعد جمع‌بندی با عددها

نگاه اول: طراحی

اول سیستم را می‌سازم، بعد صفحه را

  • سیستم طراحی از SDS (فیگما): فاصله‌ها از واحد پایهٔ ۴/۸ — کارت‌ها ۱۶، تنفس بخش‌ها ۲۴
  • مقیاس گردی ۴ قدم: کوچک برای برچسب، ۸ برای ورودی، ۱۶ برای کارت، تمام‌گرد برای دکمه‌ها
  • سایه‌های لایه‌ای: حالت عادی سایهٔ سبک، هاور سایهٔ عمیق‌تر — عمق واقعی، نه تزئین
  • پالت: سرمه‌ایِ تیره + یک خانوادهٔ آبی؛ رنگ در UI فروشگاهی وظیفه‌اش جلب توجه است نه تزئین
  • تایپوگرافی: وزیرمتن با ارقام فارسی — قیمت و تاریخ شمسی نیتیو
  • RTL یک تصمیم معماری است، نه یک صفت: گریدها، بنر کاروسل، توست‌ها و شیت موبایل همه راست‌به‌چپ متولد شده‌اند
  • میکروجزئیات حرفه‌ای: حلقهٔ فوکوس ۲پیکسلی، حالت‌های hover، بسته‌شدن با سوایپ، نقطکِ چت بدون عدد

نگاه دوم: مهندسی

ساده‌سازی، تا روی هر هاستی زنده بماند

  • صفر ابزار بیلد: HTML/CSS/JS خالص + تیلویند — کپی فایل روی هاست = دیپلوی کامل
  • موتور رندر سبک: با هر تغییر وضعیت صفحه بازسازی می‌شود، بدون پرش اسکرول؛ کرسر و متنِ در حال تایپ حفظ می‌شود
  • بک‌اند تک‌پرونده‌ای (PHP): نشست، توکن CSRF، محدودیت نرخ، سقف حجم درخواست — با سیاست دسترسی برای هر جدول
  • دیتابیس قفل موتور نیست: SQLite / MySQL / PostgreSQL / SQL Server + اتصال API به cPanel، DirectAdmin، Plesk با ویزارد نصب
  • حالت آفلاین: کل اپ با IndexedDB مرورگر کار می‌کند؛ بعداً دوطرفه با سرور هم‌سان می‌شود
  • قیمت سفارش سمت سرور محاسبه می‌شود — نه اعتماد به مرورگر؛ یعنی ضددست‌کاری و درست‌ثبت‌شده

نگاه سوم: سئوی فنی و On-Page

سئو یک افزودنی نیست — در پنل ساخته شده

  • برای هر محصول/صفحه در پنل: عنوان سئو، متا دیسکریپشن، کلمات کلیدی، اسلاگ تمیز، کانونیکال و دستور robots
  • پیش‌نمایش شبکه‌ای درست: فیلدهای جداگانهٔ Open Graph و Twitter Card برای هر صفحه
  • داده ساختاریافته: JSON-LD قابل‌ویرایش برای محصول + ریس‌کرumble‌های نشانه‌گذاری‌شده برای درک سلسله‌مراتب توسط گوگل
  • HTML سمانتیک: یک h1 در هر صفحه، سلسله‌مراتب درست، تگ‌های واقعیِ nav/article، alt تصاویر
  • سرعت به‌عنوان رتبه‌فاکتور: خروجی سبک، API سبک، Lazy-load، کش آفلاین — Core Web Vitals در حالت ایده‌آل
  • فلسفهٔ من: ابزار باید طوری ساخته شود که سئو را بشکند نه اینکه متن اضافه بنویسد — همهٔ این میدان‌ها واقعی، اعتبارسنجی و تست‌شونده‌اند

نگاه سوم: سئوی محتوا

بلاگ، موتور ترافیک قیف محتوایی است

  • کلمهٔ کلیدی قیف اطلاعاتی: کسی که «راهنمای خرید هدفون» را جست‌وجو می‌کند مشتری فرداست — بلاگ آریا دقیقاً برای همین است
  • تازه‌سازی: انتشار از پنل یک کلیک است؛ سیگنال سایت زنده برای موتور
  • عمق محتوا: بلوک رسانهٔ درشت (تصویر تمام‌عرض/نصف/یک‌سوم، ویدیو، iframe با زیرنویس و تراز) — زمان ماندگاری بالاتر
  • لینک داخلی هدفمند: مقالهٔ بلاگ → صفحهٔ محصول؛ بخش «مقاله محصولات» در هر صفحهٔ محصول؛ ریز‌لینگ از دسته به خانه — حلقه بسته
  • سیاست محتوا سمت سرور: پیش‌نویس هرگز در ایندکس نمی‌افتد؛ یعنی کنترل کامل انتشار از پنل با تست خودکارِ پوششی

AI در خط تولید

حلقهٔ «پرامپت → پیاده‌سازی → ممیزی» — شش تکر

  • طراحی: بریف + قیدها به AI؛ خروجی: نگاشت سیستم طراحی به توکن‌های CSS — من انتخاب و چیدمان کردم
  • مهندسی: ماژول‌به‌ماژول (سفارش، نشست، بلاگ…)؛ هر تکر با بازبینی امنیتی AI — حقن، جعل شناسه، دست‌کاری قیمت و موجودی
  • تست: AI نویسندهٔ تست‌های مخرب است؛ ۱۲۰ تست سرتاسری متنی که در بیلد اجرا می‌شود؛ من همه را بازبینی کردم
  • محتوا و سئو: پیش‌نویس مقالات محصول و بلاگ، تولید انبوه متا و alt و داده ساختاریافته — ویرایش نهایی مال من
  • قاعدهٔ حرفه‌ای: AI پیشنهاد می‌دهد، من تصمیم می‌گیرم. هیچ خروجی AI بدون مرور انسانی کاشته نمی‌شود
  • نتیجه: کل پروژه — طراحی، کد، محتوا، امنیت، تست — در چند روز؛ روشی که خودِ آریا برایش ساخته شده

سایتی که اعتماد نمی‌شکند، فروش هم نمی‌شکند

  • ورود سه‌مرحله‌ای: رمز ← کد یکبارمصرف پیامک/ایمیل ← نشست کوکیِ HttpOnly+SameSite + توکن CSRF
  • ثبت‌نام = ورود خودکار به پنل؛ تغییر رمز با احراز OTP و ابطال بقیه دستگاه‌ها
  • وایت‌لیست فیلدها: فیلد ناشناخته ذخیره نمی‌شود — ارتقای نقش با تزریق ممکن نیست
  • قیمت و موجودی سمت سرور · محدودیت نرخ OTP · رد بدنهٔ حجیم با ۴۱ · لاگ بدون اطلاعات هویتی
